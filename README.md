# HousePricingPrediction
Prediction of house prices

# Ideias:
Mostrar seleção de parâmetros com matplotlib

Mostrar diferenças entre modelos por matplotlib

Verificar se MAE tem 3-10% de diferença da média dos valores


# Resultados:
Escolhido: XGBoost pelo erro absoluto médio menor ($1000 a menos de diferença para Random Forest) e erro quadrático médio menor (diferença significativa para Random Forest), ambos MSE altos pela grande quantidade de outliers no dataset
